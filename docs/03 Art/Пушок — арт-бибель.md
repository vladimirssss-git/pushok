# Пушок — арт-бибель

Родитель: [[Пушок — MOC]]

## Технические ограничения

- Логическая сетка платформера сохраняет base tile **32×32**.
- Система координат игры — 640×360, физический canvas — 1920×1080
  (`renderScale: 3`, камера компенсирует масштаб). Рисованные HQ-сцены используют
  `pixelArt: false` и линейное сглаживание; старые маленькие спрайты платформера
  могут сохранять пиксельную структуру внутри своих логических размеров.
- Спрайт Пушка ~24×28 px.

## Палитра

| Роль | HEX |
| --- | --- |
| Фон | `#1b1b2a` |
| Пушок | `#f2c185` |
| Акцент / UI | `#ffd479` |
| Земля | `#3d5a45` |
| Рыбка | `#8fd3ff` |
**Красного в палитре нет.** 2026-08-07 шипы сначала получили кодовый
плейсхолдер `#c94f4f` (единственный красный), но в тот же день заменены на
авторский спрайт — красный из палитры убран. Опасность в игре читается
**формой** (треугольные острия) и происхождением (собака), а не цветом.
Заводить «цвет опасности» заново — отдельное решение, а не побочный эффект
плейсхолдера.

**Арт-долг: объекты без спрайтов.** Земля, уступ редактора и выход рисуются
кодом в `PreloadScene` (`makePlaceholder` и соседние методы) — плоские
фигуры в цветах из таблицы выше. Это плейсхолдеры, а не стиль: когда
появится пиксель-арт, меняется только загрузка ассета в `PreloadScene`,
ключи `TEX.*` и геометрия объектов остаются. Важно сохранить размеры:
земля и уступ — тайл 32×32 (уступ 64×32), выход 32×48.

## Референсы персонажей и объектов

Источник: референсные изображения, присланные пользователем в чате с Claude,
2026-08-05 (JPEG без альфа-канала, `art-src/references/`). В тот же день
обработаны (вырезан фон, обрезка, ресайз) и подключены как настоящие спрайты —
см. `История изменений` ниже и devlog [[2026-08-05]].

- **Пушок (игрок).** Рыжий котёнок, крупная выразительная морда, ярко-зелёные
  глаза с бликами, розовые уши изнутри. Дружелюбный, «мультяшный» стиль с
  чёрным контуром. Спрайт: `public/assets/sprites/pushok.png`, 24×28.
- **Рыбка (собираемый предмет).** Было два варианта, выбрана синяя
  стилизованная (`fish2.jpeg`) — совпадает с палитрой `#8fd3ff` и контрастнее
  на фоне рыжего Пушка, чем золотая (та осталась неиспользованной в
  `art-src/fish_goldfish_raw.png`). Спрайт: `public/assets/sprites/fish.png`, 26×10.
- **Шипы (препятствие).** Три коричнево-серых треугольных шипа на общем
  тёмном основании, с мягкой тенью. Контактное повреждение — задел героя,
  теряется жизнь. Статичный объект уровня, не враг. Спрайт:
  `public/assets/sprites/spikes.png`, **32×19**, точка привязки — нижняя
  грань.

  Размер пересчитан 2026-08-07: исходный экспорт был 67×40 — шире клетки
  сетки (32), из-за чего шипы наползали бы на соседние колонки в редакторе.
  Ширина приведена к тайлу, высота (19) — из исходной пропорции 1.68,
  а не подогнана под полклетки: сплющивать авторский рисунок ради круглого
  числа незачем, на сетку шипы садятся нижней гранью.
- **Злая собака (враг).** Светло-рыжая чихуахуа с оскаленными зубами и чёрными
  глазами навыкат — агрессивный, резкий силуэт в отличие от мягкого Пушка.
  Патрулирует отрезок пола, поймает героя — тот теряет жизнь. Спрайт:
  `public/assets/sprites/dog.png`, 25×34.

**Несостыковка с текущей палитрой (открыто).** В таблице выше Пушок задан как
`#f2c185` (бежево-персиковый), а на спрайте — насыщенно-оранжевый. Реальные
фото/арт использованы «как есть», без перекраски под HEX-палитру — палитру не
меняю без явного разрешения (approval gate в `CLAUDE.md`). Если решим привести
к единой палитре — отдельная задача на перекраску всех спрайтов.

**Осторожно: `dog.jpeg` похож на стоковую фотографию**, а не на рисованный арт
(в отличие от остальных трёх референсов). Перед публичным деплоем на GitHub
Pages стоит проверить права на использование этого изображения.

## Пайплайн

1. Исходники (`.aseprite`) — в `art-src/`, в git не попадают.
2. Экспорт PNG + JSON атласа → `public/assets/sprites/`.
3. Ключ регистрируется в `src/config/assets.ts`, загрузка — только в `PreloadScene`.

**Нормализация UI-кнопок Quest (2026-09-01).** Верхние кнопки рюкзака, карты
и меню должны иметь одинаковый квадратный canvas и прозрачный фон. Рабочие
файлы — `quest-btn-backpack-normalized.png`, `quest-btn-map-normalized.png`,
`quest-btn-menu-normalized.png`; исходные `*-hq.png` оставлены для истории.
Финальные прозрачные cutout-варианты сделаны встроенным ImageGen с требованием
сохранить рамку, иконку, тень и стиль, удалив только фон вне скруглённой кнопки.

**Обработка присланного JPEG-референса** (Python + PIL, воспроизведено
2026-08-07 для шипов): прозрачность по светлому фону (`min(r,g,b) >= 200`
→ alpha 0 — порог убирает и мягкую тень вокруг рисунка, иначе она остаётся
серой каймой), обрезка по `getbbox()`, ресайз до ширины ~тайла
(`Image.LANCZOS`), затем бинаризация альфы (`>= 128 → 255, иначе 0`) —
без неё при `pixelArt: true` по краям остаётся мыльная полупрозрачная
кайма.

**Перед тем как рисовать плейсхолдер — проверить `public/assets/sprites/`.**
Шипы 2026-08-07 получили кодовый плейсхолдер при том, что готовый спрайт
уже лежал в репозитории с 2026-08-05 (и был описан в этой самой заметке):
код колючек удалили 2026-08-06, а PNG остался. `grep` по ключу `TEX.*`
ничего не находил, потому что ключ тоже был удалён — искать надо по
файлам ассетов, а не по коду.

### Как передать референс/ассет агенту

Картинка, вставленная прямо в чат, агенту видна, но недоступна как файл на
диске — сохранить её в проект он не может (проверено 2026-08-05). Чтобы файл
дошёл до `art-src/`, нужно сохранить его на диск (например, в `Downloads`)
и назвать агенту путь — тогда он скопирует/обработает файл сам.

Файлы больше 5 МБ в git не коммитить.
