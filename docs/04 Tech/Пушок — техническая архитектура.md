# Пушок — техническая архитектура

Родитель: [[Пушок — MOC]]

## Стек

TypeScript + Phaser 3 + Vite. Без бэкенда, прогресс в `localStorage`.
Деплой — статика на GitHub Pages (ручной `workflow_dispatch`).

## Структура

```
src/main.ts       — конфиг Phaser и регистрация сцен
src/config/       — все числа игры
src/scenes/       — Boot → Preload → Menu → Game → GameOver
src/entities/     — Pushok и прочие объекты
src/systems/      — чистая логика: движение, прогрессия, сейв
test/             — vitest на чистую логику
```

## Три правила, которые легко нарушить

1. **Числа только в `src/config/`.** Инлайновая константа в сцене невозможна для
   тюнинга и молча расходится с дизайн-заметкой.
2. **Логика — чистыми функциями в `src/systems/`.** Всё, что зашито в `update()`,
   не тестируется и переписывается при каждой смене сцены.
3. **Ключи ассетов — только из `src/config/assets.ts`.** Опечатка в строковом ключе
   не бросает ошибку: Phaser рисует зелёный квадрат.

## Сейв

Схема версионирована (`SAVE_VERSION`). Меняешь структуру — пиши миграцию в
`src/systems/save.ts`, иначе у всех, кто уже играл, прогресс исчезнет без ошибки в консоли.

## Команды

```bash
npm run dev        # localhost:5173
npm test           # vitest
npm run typecheck
npm run build
```

## CI

- `ci.yml` — typecheck, lint, tests, build на каждый push и PR.
- `deploy-pages.yml` — только ручной запуск, `VITE_BASE` подставляется из имени репозитория.
