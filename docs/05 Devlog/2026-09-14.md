# 2026-09-14 — Контрастные балконы и препятствия

Источник решения: пользовательская проверка платформера в чате Codex. Синие
платформы выглядели чужеродно, а первый тёплый балконный вариант терялся на
пёстром фасаде.

## Сделано

- Кобальтовые платформы заменены цельными выступающими балконами.
- Финальный балкон использует крупные цветовые поля: светлую каменную кромку,
  широкую почти чёрную панель, четыре золотистых завитка, глубокую нижнюю тень
  и алые цветы. Тонкие частые прутья и большая прозрачная середина убраны.
- Пол отделён от уступов и оформлен как известняковый бордюр без синего тела.
- Бирюзовые шипы заменены тремя крупными терракотовыми остриями со светлыми
  гранями и толстым тёмным контуром.
- Каждый игровой уступ теперь рисуется одним `platformer-ledge.png`, а не
  повтором тайла пола.

## Инварианты

- Физика, управление, баланс, сейв и `customLevels.ts` не менялись.
- Размеры текстур и физических прямоугольников сохранены: пол 32×32, балкон
  64×32, шипы 32×19.
- Production не затронут.

## Проверка

- `npm test` — 131 тест прошёл.
- `npm run typecheck`, `npm run lint`, `npm run build` — успешно.
- Локальный браузерный smoke: новые балконы и шипы контрастно читаются на фоне;
  Пушок и собака стоят на полу; ошибок и предупреждений в console нет.
