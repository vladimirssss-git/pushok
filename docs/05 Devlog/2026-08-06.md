# Девлог 2026-08-06

## Погоня собаки

Пользователь: «доделай чтобы собака пробегала и если видит котёнка то
пыталась его догнать (внизу)». До этого собака (см. devlog
[[2026-08-05]]) только патрулировала отрезок пола туда-обратно, не реагируя
на игрока.

**Что добавлено** (`src/systems/patrol.ts`):

- `canSeeTarget(enemyX, targetX, targetY, floorY, rangeX, toleranceY)` — цель
  видна, только если она «внизу» (по Y в пределах `toleranceY` от пола — уступ
  выше этого допуска, собака без прыжка туда не доберётся) и в пределах
  `rangeX` по горизонтали.
- `chaseDirection(enemyX, targetX)` — направление прямо на цель.
- Обе функции чистые, протестированы (`test/patrol.test.ts`, включая кейс
  «видит на полу», «не видит на уступе», «вне дальности»).

`entities/Dog.ts` теперь получает координаты Пушка каждый кадр
(`GameScene.update()` → `dog.update(pushok.x, pushok.y)`) и переключается
между патрулём (`ENEMY.dogSpeed`) и погоней (`ENEMY.dogChaseSpeed`, быстрее —
иначе «пытается догнать» не читается). Во время погони собака может выходить
за патрульные границы (`minX`/`maxX`) и бежать по всей ширине пола — иначе
погоня на глазах утыкалась бы в невидимую стену.

**Числа** (`config/enemy.ts`): `dogChaseSpeed: 140`, `dogDetectionRangeX: 220`,
`dogDetectionToleranceY: 20` — подобраны на глаз, не балансили под реальный
уровень сложности.

**Проверено:** `npm run typecheck`, `npm test` (30/30, `patrol.test.ts` вырос
до 10 тестов), `npm run build`. Живой прогон погони в Browser pane не довёл до
конца — то же ограничение автоматизации, что и вчера (`document.visibilityState:
hidden` рвёт устойчивый held-key ввод, единичные нажатия проходят через
прямой JS keydown-диспатч не всегда). Логика — чистые функции, полностью
покрыта юнит-тестами; Phaser-обвязка (`setVelocityX`) тривиальна.
