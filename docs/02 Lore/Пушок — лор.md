# Пушок — лор

Родитель: [[Пушок — MOC]]

## Герой

Пушок — рыжий котёнок. Любопытный, лёгкий, немного неуклюжий.
Характер и имя героя — под защитой: менять только с явного согласия (см. `CLAUDE.md`, Approval gates).

## Мир

Дом, двор, крыши. Масштаб мира — кошачий: стол это уровень, шкаф это высота.

## Тон

Тёплый и добрый. Опасности — бытовые (вода, пылесос, высота), не жестокие.
